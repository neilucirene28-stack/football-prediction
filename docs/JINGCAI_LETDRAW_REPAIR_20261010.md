## 2. 194场真实数据审计结果

来源：`hidden_backfill_jingcai.jsonl`。实际日期是2026-09-01～09-20。让球分布：−1有111场，+1有57场，−2有14场，+2有10场，−3有2场。实际让平44/194=22.6804%。

原评分脚本的错误符号，在这些赛果与官方让球上会改变 **134/194** 个实际类别。这是结算事件的差异，不等于已经证明过去所有日报都错：旧日报可能用了其他计算路径，需逐条定位。修复后必须重算来自旧 scoreboard 的让球指标，不能沿用旧看板缓存做趋势比较。

按记录中的三位小数 λ、四位小数胜平负及假设ρ=−0.13重建不同阶段：

| 重建阶段 | 平均让平概率 | 最大让平概率 | 让球Brier（三项和） | 首选命中 | 首选让平 |
|---|---:|---:|---:|---:|---:|
| 原始纯Poisson | 18.9598% | 22.0447% | 0.636980 | 104/194 | 0 |
| 原始Poisson＋DC | 17.6894% | 20.4388% | 0.639804 | 104/194 | 0 |
| DC＋IPF | 21.0376% | 29.5218% | 0.611843 | 104/194 | 0 |
| DC＋IPF＋既有固定先验让平校准 | 22.7508% | 27.2609% | 0.607942 | 104/194 | 0 |

因此，“模型最高只有22%”对应原始纯Poisson口径，并非当前代码的完整生产链路；“平均低估4pp”也不能直接套到校准后输出。校准后的全局平均接近实际，不证明条件校准完美，也不说明有足够的单场让平辨别能力。

**这些数字是诊断重建，不是精确生产回放，更不是新模型严格样本外收益证据：**

- 194条全部缺 model_version、kickoff_at、snapshot_at、prediction_generated_at、feature_as_of；原输入payload和训练版本也未封存。
- 固定先验拟合截至09-30，晚于这批09-01～20数据，不能把其0.607942当作无泄漏的历史成绩。
- λ与p舍入，ρ为源码当前默认假设；缺少原始配置不能完全还原旧预测。
- 回填脚本使用收盘赔率、人工设定的赛前快照和外部临时映射；这些是潜在历史研究输入，不能当作真实当时采集／生成证据。
- source hash、逐场概率、赛果类别及阶段评分已保存到 `audit_output/jingcai-letdraw`，可重复检查。

既有让平校准在194场重建中，使总进球均值平均变化约−0.01245球。说明“只改变形状、均值必然不动”的承诺不成立；改为同源矩阵输出后必须继续评估比分和进球数。

## 4. 新输出示例及语义

每场让球对象新增：

```text
risk_view：完整概率、让平对应净胜球、Top1、Top2、覆盖和遗漏
probability_trace：Poisson / DC / IPF / final 概率，矩阵均值与WDL前后对照
probability_source：jingcai_final_score_matrix
pick_rule：argmax
```

让平概率无论多少都显示。若不是首选，也可明确看到其概率与Top2是否遗漏它。Top2覆盖是两个互斥事件概率和；不是串关保本、正收益或实战命中保证。

新增实际生成时间、特征快照时间、虚拟评估截止、live／historical_replay标签和全精度最终矩阵。Monte Carlo仍是原Poisson λ下的辅助诊断，不能当成最终IPF／让平校准后的另一个同源概率输出。

概率审计还记录实际比分网格上限和归一化前的Poisson截断尾部质量。当前生产网格仍为单队0～10球；极端λ下不保证尾部误差≤1e-6。已有score_constrain的自适应网格尚未接入生产，本次没有顺带更改原始概率模型。

`fixed_odds_expected_net=p×odds−1`仅按可得十进制固定赔率做算术，未包含产品实际兑付规则、交易成本、赔率时效或选择后校准验证。概率差和模型正EV候选均不代表已验证优势。
