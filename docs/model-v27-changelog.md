# 模型 v2.7 更新日志（2026-10-08）

## B深修：统一校准层与比分矩阵（IPF）

### 根因
`predict()` 中：
- 第4步：`matrix = score_matrix(lam_h, lam_a)` → `p_model`（raw）
- 第7步：ensemble + Platt → `p_final`（校准后 1X2，报告胜平负首选用这个）
- 第9步：`top_scores`、`handicap_1x2`、`total_goals` 等直接用**原始 matrix**

胜平负首选（校准后）与比分首选（raw 矩阵）来自两个分布，必然打架
（如 10-07 的 003/004：胜平负首选胜、比分首选 1-1）。

### 修法
校准后对 matrix 做 IPF（iterative proportional fitting）：
1. 从 matrix 算 raw 1X2 边际
2. 目标边际 = 校准后 `p_final`（未 round 值）
3. 主胜/平局/客胜三区域构成完备划分，单轮乘法缩放即精确收敛
   （区域内相对概率不变 = 最小 KL 散度调整）
4. 所有全场衍生项改从校准后矩阵计算；raw 值保留为 `*_raw` 对比字段
5. 让球口径：先从校准矩阵算 raw handicap_1x2，再走现有让平校准（顺序不变）
6. 半场子模型（half_time_probs / half_full_1x2）是独立 HT 口径，
   内部自洽且无校准目标，不做 IPF；Monte Carlo（λ 抽样验证工具）不动

### walk-forward 验证（419 场回填，lam 重建矩阵，0/419 失配）
| 指标 | 修前 | 修后 | 结论 |
|---|---|---|---|
| 胜平负 Brier | 0.5692 | 0.5692 | 持平（IPF 不改变 p_final，构造性保证）|
| 比分 Top2 命中率 | 20.8% | 22.2% | +1.4pp，未恶化 |
| 方向一致率（1X2首选==比分首选） | 16.3% | 34.7% | **+18.4pp，翻倍以上** |
| ├ 强首选（≥55%，n=108） | 47.2% | 83.3% | +36.1pp |

| └ 弱首选（<45%，n=179） | 2.8% | 3.9% | +1.1pp（分布太平，众数天然偏平局） |

### 诚实注
- IPF 保证边际一致，但**不保证**单个最高概率比分的方向与 1X2 首选一致
  （众数可落在低概率但更集中的区域，这是概率论基本性质，非 bug）。
- 弱首选场次（<45%）的一致率仍然很低——分布本身太平，任何矩阵调整都救不了，
  这是展示层问题，不是模型问题。
