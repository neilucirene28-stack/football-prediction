# P1实验报告 v2：双Poisson混合（修正版）vs 独立负二项（2026-10-09）

> 本报告替代 `score-dist-p1-report.md` 中实验A的结果（原A因实现bug作废）。
> Bug：`mixture_matrix()` 是主客独立边际混合再乘积（4交叉状态），非共享慢/快两状态。
> 修复：`m[i][j] = 0.5·Pois(i,slow_h)·Pois(j,slow_a) + 0.5·Pois(i,fast_h)·Pois(j,fast_a)`。
> 新增4项检测测试（协方差/特定格子），bug代码上失败、修复后通过。

## 数据与方法（与v1相同）
194场竞彩回填（2026-09-01~09-20）。基线 = v2.10（Poisson + DC ρ=-0.13 → IPF）。
Walk-forward：expanding window，8个测试日共88场。
留出集：训练09-01~09-14（130场），测试09-15~09-20（64场）。
Bootstrap：按比赛日聚类，2000次。

## 结论：仍然不上线（诚实否决）

1. Walk-forward上修正后的A反而**差于基线**（+0.0005），bug版本虚假的-0.0021来自错误的独立混合
2. Bootstrap 95%区间上界仍为正（+0.00044），未达严格标准（上界<0）
3. P(优于基线)从66.6%升至95.4%，但点估计的改善幅度仍可忽略

**修正带来的认知变化**：原bug版本（独立混合）人为夸大了A的效果；真正的共享节奏模型在walk-forward上没有优势。δ被选得更小（0.1 vs 0.25）说明数据支持的过度离散比之前估计的更弱。

**保留价值**：`engine/score_dist.py` 两种分布实现 + 4项协方差检测测试保留作未来实验基础；194场样本太小，攒到500+场可重跑。
