# 方法论：Elo → Dixon-Coles → 市场融合

本项目的方法论遵循"透明、可复现、可证伪"三原则，
参考 [Hicruben/world-cup-2026-prediction-model](https://github.com/Hicruben/world-cup-2026-prediction-model)
的路线：Elo 评分 → Dixon-Coles 二元 Poisson →  proper scoring rules 回测。
不做机器学习黑箱，不抓取不可复现的私有赔率。

## 1. 实力估计（双轨）

- **Elo 轨道**：长期实力，`E = 1/(1+10^(-ΔR/400))`，赛后零和更新。
  主场优势常数默认 +65 分，K=30（欧国联级别）。
- **攻防强度轨道**：近 8 场主客拆分样本，
  `attack = 场均进球 / 联赛每队场均`，`defense = 场均失球 / 联赛每队场均`。
- **时间衰减**（v2.1）：样本权重 decay**i（i=0 最新，默认 decay=0.90），
  近期比赛更能代表当前实力。
- **对手强度修正**（v2.1）：每场进球按对手攻防强度归一化，
  `adj_gf = gf / opp_defense`，对弱队刷进球自动打折。

## 2. 进球期望

```
λ_h = attack_h × defense_a × 联赛每队场均 × 主场加成(1.12)
λ_a = attack_a × defense_h × 联赛每队场均
```

已确认伤停才做乘法修正（主力前锋缺阵 ×0.92 等）；未经确认一律不调。

## 3. 比分矩阵（Dixon-Coles）

独立 Poisson 乘积后，对 (0,0)/(1,0)/(0,1)/(1,1) 四格做 tau 修正
（默认 ρ=-0.13，低比分正相关），再整体归一。
1X2、BTTS、大小球、亚盘、竞彩让球**全部从同一矩阵聚合**，
不用 1X2 拍脑袋替代让球盘。

## 4. 市场融合

- 市场基线 = 即时欧赔的 Shin 去水概率（退化：等比去水）。
- 融合权重按数据完整度等级（S 0.55 / A 0.50 / B 0.40 / C 0.30），
  复盘给出的模型优势（edge）可微调 ±0.10，上限 0.65。
- 融合后 1X2 严格归一 100%；禁止手动调概率。

## 5. 价值与纪律

- `edge = P_final − P_market > 5%` 记为价值方向；仓位用四分之一 Kelly。
- 只输出方向与价值星级，不输出金额、不下单。
- D 级数据直接拒给概率（`insufficient_data`）。

## 6. 回测（walk-forward，防泄漏）

每场只用开赛前快照预测，赛后用 proper scoring rules 评分：

- **Brier**、**LogLoss**、**RPS**（足球标准的有序评分），越小越好；
- **校准曲线**：按预测概率分桶，看桶内实际胜率是否落在对角线上；
- **CLV**：推荐时赔率 vs 收盘赔率，长期为正才是真有效。

只有时间顺序盲测显著优于市场基线，才允许上调模型权重——
权重调整全留痕，见 `GET /api/backtest/summary`。
