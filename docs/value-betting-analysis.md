## 二、置信区间：21.3%的真实值范围

历史136场、命中29场，95% Wilson置信区间：

**真实命中率 ∈ [15.3%, 28.9%]**

解读：
- 下限15.3%：即使运气差，真实值也不太可能低于此
- 上限28.9%：即使运气好，真实值也不太可能高于此
- 区间宽度13.6个百分点——样本还太小，结论不稳

### 10-09期0/5是异常吗？

在p=21.3%假设下，P(0/5) = (1-0.213)⁵ = **30.1%**

三成的事发生了，纯属波动。**不构成否定value策略的证据。**

反过来想：如果value真实命中率是15%（CI下限），P(0/5)=44%；如果是29%（CI上限），P(0/5)=18%。无论哪种，0/5都不意外。

### 盈亏平衡考量

value投注的盈亏不只看命中率，还看赔率。假设平均赔率3.0（对应33%隐含概率）：
- 盈亏平衡命中率 = 1/3.0 = 33.3%
- 当前21.3% < 33.3%，**如果平均赔率真是3.0，当前是亏损的**

但这没算edge筛选的价值：value要求edge>0.05，即模型概率比市场高5个点以上。如果模型校准良好，长期期望应为正。需要结合实际赔率计算ROI，**不能只看命中率**。

### 建议

1. **继续攒样本**：目标先到258场（±5%精度），还差约122场
2. **记录完整字段**：每条value必须记录outcome类型、模型概率、市场赔率、edge、实际赛果、ROI
3. **不要因0/5动阈值**：30%概率事件不构成证据
4. **不要因21.3%肯定策略**：CI下限15.3%，且没算ROI
