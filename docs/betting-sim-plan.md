# 模拟投注实验方案 v2：按竞彩真实玩法（混合过关 + 单关）

> 实验性质：**全程模拟，不产生任何真实投注，不花一分真钱。**
> v2 改动（2026-10-15，用户纠正）：不再只玩胜平负单关，改为竞彩真实玩法——
> 五大玩法可混合过关，也可串；单关只在单关开售场次玩。

## 1. 基本设定

| 项 | 设定 |
|---|---|
| 虚拟本金 | ¥10,000（2026-10-15 起） |
| 周期 | 7 个投注日：10-15 → 10-21，10-22 出周总结 |
| 玩法 | 五大玩法：胜平负 / 让球胜平负 / 比分 / 总进球数 / 半全场 |
| 参考依据 | **挖掘的比赛结果 + 预测的模型结果** 两者都用：选腿用模型各玩法概率，质量门用挖掘数据（完整度/分歧/一致性） |
| 赔率 | 选场时从 500.com 四页面实时抓取（269 胜平负/让球、271 比分、270 进球数、272 半全场），不用预测文件里的旧 SP |
| 单关/过关标志 | 每场每玩法取自 500.com `data-subactive`（`dg`=单关开售，`gg`=过关开售） |

## 2. 选腿规则（每条腿都要满足）

1. 引擎置信度 confidence 为 **A 或 B**（C/D 不投）。
2. 数据完整度 grade 为 **A 或 B**（C/D 不投）。
3. 引擎**无严重分歧标记**（`divergence` 为空）。
4. 期望值 **EV = 模型概率 × 实时 SP − 1 ≥ 8%**。
5. 比赛**未开赛**。
6. **防彩票注**：腿概率 **p ≥ 10%** 且赔率 **SP ≤ 12**（比分/进球数等冷门市场尾部概率估计误差大、水位高，彩票型冷门一律不投）。
7. **一场只取 1 腿**：同一场比赛各玩法中只留 EV 最高的那个选项，不允许同一场多方向对冲。

各玩法模型概率来源：

| 玩法 | 概率来源 |
|---|---|
| 胜平负 | `p_home/p_draw/p_away` |
| 让球胜平负 | `derivatives.handicap_1x2.p_*_full` |
| 比分 | `derivatives.top_scores`（仅前 5 名；胜其它/平其它/负其它模型无法定价，不投） |
| 总进球数 | `derivatives.total_goals_exact_full`（0–6、7+） |
| 半全场 | `derivatives.half_full_1x2_full`（胜胜…负负 9 项） |

## 3. 组票规则

- **混串票**：每天最多 2 张（容错组合）。取 EV 最高的 3 场比赛的腿：
  - 3串1：3 条腿全串，串关 EV ≥15% 才出；
  - 2串1：其中 EV 最高的 2 条腿再串一张，串关 EV ≥15% 才出。
  - 每张票独立算四分之一凯利、独立上限本金 3%、下限 0.3%。一腿翻车时 3串1 归零但 2串1 仍可中。
  - 只有 2 场合格时只出 2串1；不足 2 场则当日无串票。
- **单关票**：串票之外的剩余腿中，该玩法单关开售（`dg=1`）且 EV≥8% 的，最多 **2 注**，各按四分之一凯利、上限 3%。
- **每日总投入上限**：本金 **15%**（先串票，后单关，超了砍单关）。
- 注：2串1 与 3串1 共享腿，严格说是相关头寸而非独立注；每票独立算凯利是简化处理，仓位上已用 3% 上限和 15% 日上限双重约束。

## 4. 风控（不追损是铁律）

- 输了不加倍、不追加、不补单。
- 单日本金回撤 **20%** → 当日停手。
- 累计回撤 **30%** → 提前终止实验并汇报，不赌到爆仓。

## 5. 结算口径

- 按选场时记录的实时 SP 结算（竞彩实际按最终 SP 结算，模拟用选场时 SP 是近似口径，周总结里说明偏差）。
- 串票：**全中才中**，返还 `stake × Π SP_i`；任一腿输则整票输。
- 串票中某腿推迟/取消：该腿按 **SP=1.0** 计（竞彩真实规则），其余腿继续算；全部腿取消则整票退款。
- 单票推迟/取消：退款（void）。
- 半全场结算需半场比分，结算数据格式含 `ht_score`。

## 6. 每日流程（定时任务 11:30）

1. 结算已完赛的未结票（查比分+半场比分，双源交叉）。
2. 生成当日竞彩预测（小店火赛程 + 500.com 官方 SP → `batch_predict_today.py`）。
3. 跑 `betting_sim.py select`：实时抓 500.com 四页面赔率 → 选腿 → 组票 → 写账本。
4. 聊天发简报：当日票、本金、盈亏、ROI。

## 7. 文件

- 脚本：`scripts/betting_sim.py`（`select` / `settle` / `report`）
- 账本：`data/betting-sim/ledger.jsonl`（每票一行，含 legs）
- 本金：`data/betting-sim/bankroll.json`
- 方案：本文档

## 8. 诚实声明

- 7 天 ≈ 15–25 票，方差主导结果，**一周的盈亏证明不了策略有效**，只能看执行纪律和过程指标（命中率、平均 EV 实现率）。
- 串关放大方差：3串1 即使每腿 EV 为正，连黑也常见；四分之一凯利 + 3% 上限是防爆仓的，不是保盈利的。
- 长期看，博彩市场水位（overround ≈ 10%+）对玩家不利；本实验的默认假设是“大概率小亏或打平”，如果一周下来是正收益，先怀疑运气，再谈策略。
