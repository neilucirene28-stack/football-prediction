# 竞彩第六轮：牌数对赛果的增量验证

本轮累计保留第五轮，只新增竞彩离线研究和只读导出。生产预测器没有导入候选模块，没有改变λ、胜平负或任一比分矩阵，也没有拟合生产参数。北单专用文件不变。

## 候选与对照

`engine/jingcai_cards_validation.py`以已封存的竞彩全精度胜平负为log概率偏置，拟合带固定L2收缩的多类概率修正。输入为预测当时可得的双方当前赛季场均黄牌差/和、场均红牌差/和、两队预测至少一张红牌概率。使用场均值避免赛程数量不同直接扭曲比较；累计数量、观测场数和覆盖率仍由第五轮模块展示。

同一样本比较三个结果：原概率、只拟合截距的整体校准对照、加入牌数特征的候选。候选只有在两种对照下都不变差才通过研究筛查，不能把整体校准收益冒充牌数新增信息。模型可学到正/负/零关联，没有“黄牌越多必然更弱”或固定红牌减百分比。

候选仅描述赛前纪律特征与赛果的条件关联，不识别一张红牌的因果效应，不模拟红牌分钟、实时比分或罚下位置，也不学习某球员停赛损失。它不能替代带事件分钟和暴露时间的红牌条件模型。

## 数据准入与时间边界

- 接受数据库导出的封存预测+结算行，使用已有竞彩账本校验；必须live、原输入摘要匹配、真实声明的赛前生成/封存顺序、明确模型版本、结算来源及完整精度概率。
- 必须存在当时可得的当前赛季统计。双方至少5场牌数完整记录、导入记录覆盖率至少80%。缺失不填零；历史聚合先验不能代替当前赛季特征。
- 使用原输入重新计算牌数，核对保存的当前赛季数量、红牌概率、快照截止、来源SHA及历史/别名数据版本。当前模块版本无法重现的旧记录不混入。
- 实际本场结算红黄牌不进入特征，只用全场比分构造训练标签。摘要和可得时间是声明绑定，不独立证明来源真实；生产前仍需采集原件证据。
- 每个竞彩模型版本单独训练。每个物理比赛/版本保留最早合规预测，冲突比分/联赛整组排除，重复结算的最晚可得时刻用于训练准入。
- 按UTC开球日分批测试。训练结算必须严格早于该批最早赛前快照，训练开球必须早于批次最早开球；同场ID排除。同批比赛不能相互提供标签。
- 标准化只用训练集。固定ridge=0.1、学习率0.1、250次迭代；不扫描参数或自动选择测试起点。数值截断和固定优化器只是候选设计，不声称最优或已收敛统计解。

## 研究门槛与生产边界

每个测试批至少200场可得训练记录；累计测试至少100场且至少3批。汇总同时要求对原模型与截距对照的Brier差值95%正态近似上界不大于0、LogLoss不变差，且每批Brier均不变差。Brier为三类平方误差之和，不除以3。

报告保留各批训练/测试场数、截止、最晚训练结算、两种成对比较及阻断原因。区间未处理赛程/球队关联或反复试验选择，门槛不是“证明有效”。若测试起点或设计在查看结果后修改，必须重新锁定未使用的独立测试集。

`research_screen_passed=true`也不会启用生产。`production_enabled`固定false；没有自动加载候选权重，也不输出可以直接挂到现有Platt配置的权重包。生产仍需独立锁定验证、来源核查、按联赛和赛季稳定性检验，并把获准的WDL修正一致地整合到比分矩阵/让球/半全场/MC。仅改WDL会重新造成多玩法冲突，因此本轮不这样做。

## 在竞彩测试环境执行

只读导出一个真实竞彩版本（使用已配置的竞彩测试库DATABASE_URL，不在命令里粘贴凭据）：

```bash
python3 scripts/export_jingcai_cards_ledger.py \
  --version '真实竞彩版本' --days 365 --output /private/jingcai-ledger.jsonl
python3 scripts/validate_jingcai_cards_impact.py \
  --input /private/jingcai-ledger.jsonl \
  --test-start '预先固定的ISO时间及其时区' \
  --output /private/jingcai-cards-validation.json
```

导出查询在只读事务中执行，竞彩过滤在SQL取数前、版本明确、不静默截断；文件权限0600，不覆盖既有导出，不打印连接串。原输入可能含私有数据，保留在授权环境，勿把原始导出提交公共仓库。脚本只读原数据库；本次没有连接真实数据库。

离线验证只需JSONL，不需要数据库/网络。JSON行须包含prediction_id、match_id、model_version、league、kickoff_at、predicted_at、settled_at、source、3个存储概率、home_goals/away_goals，以及payload={input:原输入,result:原预测}；可附半场和结算牌数。不能从缺快照的旧汇总拼造这些字段。
