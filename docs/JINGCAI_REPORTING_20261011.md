# 竞彩 v11：首发确认与比分解释

本轮只调整竞彩置信评分和解释层，不改胜平负、让球或比分概率。商业情报影响系数仍未启用，未部署到 MUSE，没有准确率改善的验证结论。

## 首发确认

旧逻辑用 injury 字段是否非空代替首发确认。现在只读取已经过身份、证据、赛前时间校验的球队情报，以及分维度选择的首发来源。主客队均 confirmed 才取原有确认系数1.0，其余保留原有0.60；没有引入新的训练参数。预计首发、缺失、来源隔离冲突不能获得确认加分。两条有效情报链状态不一致时保守处理，不跨来源合并球员。

confidence_score 仍是启发式的数据质量与信号一致性评分，不是经过经验校准的命中率。字母等级仍沿用完整度及风险降档规则，不是分数区间。新增 confidence_audit 给出实际采用的首发状态、系数与解释；当前不宣称已经完成置信度的统计校准。

## 比分说明

竞彩一致性检查不再把单个最高概率比分与汇总胜平负方向不同判作冲突，也不再要求大球倾向必须对应大比分众数。保留原有亚盘方向检查，后续仍需验证其合理性。

保留原始 Top5 单比分，新增 score_explanation：胜平负首选、总体众数、首选方向内的比分参考。所有单比分概率都来自原有完整矩阵，不重新归一、不改分布，不强行换成更大比分。字母信心和评分可能变化，但这不代表胜率发生变化。

## 验证边界

新增11项合成逻辑测试；核心632通过、1项缺psycopg跳过、1项北单分支排除；采集器70通过。原30场输入同配置只读回放对比v10，胜平负全精度和比分矩阵最大差异为0。回放不增加赛前情报、不改旧记录、不生成新赛前预测，不能证明准确率提高。
