# 竞彩v15：零平局首选核查、防平解释与分类验收

用户指出胜平负没有一个首选平。核查证实这是上轮未解决的盲点；不能以总体命中提高声称平局识别已经改善。本轮拒绝会降低总命中率的强制平局策略，修复输出和验收，也修复一个会影响极接近平局首选的精度问题。未部署，没有改写任何历史赛前预测。

## 查到的事实

原22场封存输入中21场完赛，实际7平；v12/v13原件及v14候选都是0个平局首选。v14这21场的平局概率之和5.059878，不是0。731场公开后续赛季研究实际193平，v14平局概率合计190.005299，但最大概率单选没有选过平。

平局概率总量接近实际频率，不证明每场预测已经校准；它也不意味着首选必须按这个数量分配。按最大概率单选与各类别召回率是不同问题：731场v14主胜召回85%、平局0%、客胜36.24%，宏平均召回40.41%。需要一起评估，不用总体准确率遮住平局零召回。

## 测试过而没有采用的概率/决策改动

只在2025-01-01—03-01的181场拟合平局专用校准，在03-01以后240场选择，随后查看已见过的731场；未使用当前21场拟合。

专用概率校准不改变原主胜/客胜相对比率，使用严格早期数据标准化与正则化；失败的系数全部留在research/DRAW_REPORT.json。研究参数选择仅用于实验，RESEARCH_SELECTION.json不能拿来当生产配置。

提高平局选择次数不等于提高预测质量。代价策略不修改概率，但会选择并非最大概率的结果；不能将它伪装成最可能结果。本轮没有采用这类覆盖。

## 实际保留的代码修复

1. 新增wdl_draw_view：输出全精度平局概率、概率排名、单选首选、概率最高双选、防平双选及各自真实概率和。两个结果组合不是单选，不计入单选命中率。
2. 显示战绩模型与市场在平局上的分歧。011场战绩模型原来首选平，融合后首选负；明确呈现该分歧，不直接覆盖融合概率。历史分歧样本并未证明覆盖更好。
3. 复盘按模型版本增加3×3混淆矩阵、各类别精度/召回率、宏平均召回、平局期望总量和零平首选批次提示。未知赛果不记成0:0；没有平局首选时平局precision为未知None，recall在实际有平局时为0。
4. 修复单选先四舍五入再取最大值的问题。例如真实胜0.35001、平0.35002，显示均0.350；旧推荐可能因显示同值选择胜，新推荐按全精度正确选择平。该缺陷不是当前21场零平的主要原因，这21场平局概率本来就未超过胜/负。
5. 现有全精度概率、比分矩阵、lambda不变。22场原输入候选逐场与v14完全相等；默认矩阵策略仍兼容。没有宣称平局单选识别已解决。
