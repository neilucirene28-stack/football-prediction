# 足球量化预测模型框架（v2.4，2026-10-02 现行生产版本）

> 配套代码：`~/workspace/football-prediction-v2/`，GitHub v2 分支。
> 引擎 `engine/` 为纯函数（无 DB、无网络），全部数学可离线单测。

## 一、预测流水线（`engine/predictor.py::predict`）

```
输入校验（快照时间必须早于开球时间，防泄漏）
 → 完整度评分 completeness（S/A/B/C/D；D级直接拒给 insufficient_data）
 → 实力估计 → 进球期望 λh/λa（含H2H微调）
 → Dixon-Coles 比分矩阵（ρ=-0.13）
 → 三路信号：模型矩阵 / 市场去水 / Elo
 → 背离门控检查（divergence_gate=0.15）
 → 三信号动态融合 → Platt校准（回测拟合参数经config传入）
 → 全部衍生市场从同一矩阵聚合
 → 价值检测（edge>5%）+ 四分之一Kelly
 → 一致性检查 + 四因子置信度 + 冷门风险
 → 完整度门控 Monte Carlo（≥60分才跑，20000次）
 → V4.2/V4.1 格式输出
```

## 二、实力估计（双轨 + 三修正）

- **Elo 轨道**（长期实力）：`E = 1/(1+10^(-ΔR/400))`，主场优势 +65 分，K=30，赛后零和更新。
- **攻防强度轨道**（近期状态）：近 8 场主客拆分，
  `attack = 场均进球/联赛每队场均`，`defense = 场均失球/联赛每队场均`。
- **修正1 时间衰减**：样本权重 `decay^i`（i=0 最新，默认 0.90）。
- **修正2 对手强度修正**：`adj_gf = gf / opp_defense`，对弱队刷的进球自动打折。
- **修正3 联赛级别**（`LEAGUE_TIERS`）：跨级比赛进攻 ×0.85、失球 ×1.18（保守初值，待回测校准）。
- **收缩**（v2.4）：攻防评级向联赛均值收缩，`shrink_prior=3.0` 场先验（小样本 λ 3.97→3.34，避免极端样本误导）。
- **H2H 微调**（v2.2修好"只记录不生效"）：近3场净胜球 ×0.01，上限 ±0.03，
  `λh×=(1+adj)`，`λa×=(1-adj)`。
- **伤停**：只有确认的主力缺阵才做乘法修正（如主力前锋 ×0.92）；未经确认一律不调，**绝不编造**。

进球期望：`λh = attack_h × defense_a × 联赛场均 × 主场加成1.12`，`λa = attack_a × defense_h × 联赛场均`。

## 三、比分矩阵（Dixon-Coles）

独立 Poisson 乘积后，对 (0,0)/(1,0)/(0,1)/(1,1) 四格做 tau 修正（ρ=-0.13，低比分正相关），整体归一。
**1X2、BTTS、大小球、亚盘、竞彩让球、半场胜平负全部从同一矩阵聚合**，不用 1X2 拍脑袋替代让球盘。

- 竞彩让球口径（已核验）：`rq<0 = 主队让球`，`adj = margin + rq`。
- 总进球：期望 + 全分布 + 主要区间；半场模型 `ht_factor=0.44`。
- 模型合理盘口 `fair_handicap` + 盘口共振/背离标记。

## 四、市场信号与三信号融合

- **市场基线**：即时欧赔 Shin 去水概率（退化时用等比去水）；记录 overround；初盘→即时漂移 `market_drift`。
- **融合权重**（`fusion.py`）：模型主信号按完整度定锚 S 0.55 / A 0.50 / B 0.40 / C 0.30，
  剩余按 7:3 分给市场/Elo；缺失信号权重为 0、其余重归一；复盘 edge 可微调 ±0.10，上限 0.65。
- **背离门控**（v2.4）：模型与市场首选方向不一致 **且** 概率差距 > 0.15 时，
  自动⚠️警告、信心降一档、冷门风险 +15%。——回填证据：严重背离时市场赢 77%、模型赢 23%，**背离时不硬扛**。
- **Platt 校准**（v2.2）：回测拟合的 Platt 参数经 config 传入 `predict()`，融合后逐项校准再归一。

## 五、价值、置信度与风险

- `edge = P_final − P_market > 5%` 记为价值方向；仓位四分之一 Kelly；**只给方向与星级，不给金额、不下单**。
- **置信度 = 数据质量 × 模型一致 × 市场稳定 × 阵容确定**（四因子）。
- **一致性检查**：1X2/亚盘/大小球/比分方向互相印证，不一致则降级。
- **冷门风险**：top比分分散度 + 盘口漂移 + 平局概率综合。
- **Monte Carlo**：完整度 ≥60 才跑 20000 次模拟；以下直接跳过。

## 六、红黄牌 MVP（`engine/cards.py`，独立模块）

football-data.co.uk 4赛季×5联赛 7156 场 → 联赛基线（西甲总黄最高~4.85、德甲最低~3.9、意甲红牌最多；
仅英超有 37 名裁判统计）。球队吃牌/造牌 × 主客场 × 联赛基线 + 收缩；裁判乘子权重 0.25（生涯<5场不用）；
红牌单独建模。输出：总牌期望、分队期望、O/U 3.5/4.5、booking points、P(红牌)。
walk-forward 实测：O/U 3.5 Brier 0.2463 vs 恒均值基线 0.2476——**仅微弱优于 naive，定位是分析覆盖，不宣称 edge**。
无数据 → `insufficient_data`。

## 七、自学习（影子模式，不进生产权重）

- **Hedge 自适应权重**（`adaptive_weights.py`）：η=√(8lnK/n_eff)，90 天半衰期，样本<15 不激活；
  只记录"如果用了会怎样"，不自动调参。
- **Pi-rating 第4信号**（`pi_ratings.py`，影子）：冷启动双方未知时无信号；测试发现 α≠β 时主客场各自不守恒、仅球队总分零和——用之前先修。
- 预测持久化（`predictions` 表快照信号/权重/赔率）+ 幂等结算 `scripts/settle.py`（Titan007"比赛结束！比分"才结算）+
  评分看板 `scripts/scoreboard.py`（滚动 Brier/log-loss，分市场分联赛，**先看不调**）。

## 八、资金流向（`market_flow.py`，影子，未验证）

"钱去了哪"本身几乎无增量价值（赔率已把资金吃进去）；有支撑的是三类"市场在动"信息：
初盘→即时漂移 `drift`（CLV t=3.2~5.5）、sharp vs 零售分歧 `sharp_divergence`、成交量作可信度权重 `volume_weight`。
数据源：Titan007 90家欧指初盘/即时快照 + Polymarket 公开API（免费真成交量，小联赛常无覆盖）。
国内竞彩单场销量无公开数据，第三方投注比例不可信——**不用**。缺失是合法输出，禁回填。

## 九、回测纪律（walk-forward，防泄漏）

每场只用开赛前快照预测；指标：Brier、LogLoss、RPS（有序）、校准曲线、CLV。
**只有盲测显著优于市场基线才允许动生产权重**，调整全留痕。

### 2026-09-30 竞彩194场回填结论（诚实版，决定当前参数 freeze）
1. 让平系统性低估：实际 22.7% vs 模型 18.0%（-4.7pp）；|rq|=1 时 23.8% vs 19.0%。真问题是**形状**不是宽度：
   模型赢2球给多（12.4% vs 实际8.2%）、赢1球给少（19.3% vs 21.6%）。Dixon-Coles ρ=-0.13 在让平口径下是错方向参数。
   差值+5.0pp、SE≈3.0pp、p≈0.10——只够立项调查，不够定生产参数（约需500场让球样本）。
2. 严重背离 28/194（14.4%）：方向明确样本中市场赢 77%、模型赢 22% → 背离门控已上线。
3. 初盘→收盘漂移有信号：热门被追捧 60.0% 打出（n=55）vs 被抛弃 34.4%（n=32）。
4. 校准：纯市场 Brier 0.2964 > 融合 0.3030 > 纯模型 0.3275——**证据不足，不调生产权重**。
5. 总进球偏差 -0.14（MAE 1.46），无系统性偏差。
