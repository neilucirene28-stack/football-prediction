# 竞彩v14：胜平负、整数让球、比分专项迭代

本轮已完成代码与研究比较，计算版本2.12。默认概率策略保持v13，候选参数独立保存，没有部署到线上，也没有改写实际赛前预测。研究数据为同源公开英冠、德乙历史CSV；没有使用北单代码、参数、预测账本或结算样本。

## 本轮改动

1. 胜平负新增显式市场权重，保留无市场时的原降级路径。候选在历史选择窗口选出市场权重0.75，模型与Elo分享其余权重；本研究没有Elo。赔率去水、全精度和配置版本绑定继续保留。
2. 比分新增市场条件化计算：按融合胜平负的主胜/客胜相对概率拟合进球强度比例；有来源和可得时间的2.5球大小赔率时，允许融合总进球均值。然后将同一比分矩阵投影到已确定胜平负概率。表内lambda_home/away仍是原战绩模型强度；实际比分候选强度见score_shape_audit.effective_score_lambdas，不混淆这两个阶段。
3. 整数让球新增赔率融合候选：让球目标投影到与胜平负兼容的可行集合，再在比分矩阵内部调整。主让1球时，让负概率必须等于平局加客胜；主受让1球时，让胜概率必须等于主胜加平局。不得为了预测让平打破这些关系。
4. 比分Top2明确使用全矩阵概率最高的两个比分及其概率和。胜平负方向内参考另计，不做diverse强制重排，也不把Top5或两种口径混进Top2命中统计。
5. 有效的handicap-only输入在新入口可运行。原Muse022失败payload与堆栈仍缺失，因此不能宣称已经重现并修复那个特定错误。

## 独立参数与输入

默认：market_weight=null，score_shape_mode=legacy，score_total_market_weight=0，handicap_market_weight=0。默认22场完整矩阵与原封存输入的v12/v13结果逐场相等，新增解释字段不改变概率。

研究选择的参数：market_weight=0.75，score_shape_mode=market_conditioned，score_total_market_weight=0.5，letdraw_strength=0，handicap_market_weight=0。固定让平先验训练于2026-09，不能拿到2025验证期使用，所以研究关闭该先验。不能把本报告基线描述成原线上参数的实盘统计。

新goals_market对象含line=2.5、over、under、source、available_at，可含collected_at。只支持无走盘的2.5球盘口；缺来源或可得时间排除，未来时间拒绝。原22场输入未提供该字段，不补造。因此当前21场候选没有应用大小球市场的总均值融合。

handicap_sp仍支持原三向赔率对象/序列。融合要求明确本场整数handicap_line以及赔率source、available_at；可加line字段与本场校验。缺证据仅作诊断。核心校验调用方声明，不能代替采集器对原响应的认证。

让球赔率融合权重没有历史官方盘口样本训练，默认0。0.5只用于当前输入的只读影子诊断，没有升为推荐参数。

## 验证与边界

完整代码工作树：733项通过；penaltyblog未安装跳过1项；北单路径排除1项；11项soccerdata外部集成测试未运行。采集器70项通过。独立交付核心的40项专项检查通过，CLI和22场独立入口比较通过。数据库生产连接与部署未验证。

公开6个CSV原件实际采集于2026-10-11，字节与原HTTP收据SHA一致。非closing的AvgH/AvgD/AvgA与Avg>2.5/Avg<2.5参与研究；未使用closing字段、赛中牌数或赛后技术统计作为赛前特征。历史首次可得时间无法认证，赛前原生票池与官方整数让球缺失，公开赛果已在早前研究查看，所以不自动提升为线上默认。

后续应收集同源、真实赛前封存的胜平负、整数让球及2.5球大小赔率，用随后新比赛检验三项的增量，并先核对Muse与本项目输入/配置差异。缺来源、赔率或战绩不填零，不补造历史记录。
