## 已复现的问题与修改

| 问题 | 复现结果／原因 | 现在的行为 |
|---|---|---|
| 核心数值未校验 | NaN联赛均值会输出NaN概率；主胜赔率−1会输出主胜概率1.1475；负进球记录照常参与建模 | 竞彩拒绝非法核心输入，并统一抛PredictError；原调用方数据不被修改 |
| 历史和特征时序未检查 | payload.snapshot合规不代表每一行历史或赔率真的在此时可得 | 明确声明的可得／采集／特征时间必须≤snapshot；同日历史结果必须声明completed_at且≤snapshot |
| 交锋新旧取反 | 采集器最新在前，原预测器却取h2h[-3:] | 竞彩有完整日期时按最新在前整理；取h2h[:3] |
| 主客场字段不一致 | 部分回填给home_away，引擎消费venue | 竞彩入口在venue缺失时接受合法H/A/N别名；未知venue不被计成已知拆分 |
| 固定0～10球网格 | 高λ下较多尾部质量被截掉后归一化 | 竞彩从10开始自适应扩大，原始Poisson双队联合遗漏质量≤1e−6，硬上限30 |
| 半全场多出网格外质量 | 重加权目标矩阵以外的比分仍保留原权重，再归一化，改变目标胜平负边际 | 竞彩启用strict_ft_grid：目标网格外权重为0，半场模板覆盖目标支持集 |
| 辅助信号混入非法数值 | AF负概率、NaN，或让球SP无穷值可能影响背离信号 | 保留旧接口容错：排除非法可选信号，并在input_audit记明字段与原因 |

赔率核心字段odds/opening_odds如果提供，必须包含home/draw/away三项、各项有限且>1。缺失或空对象仍表示缺市场信号。Elo、联赛进球均值、进球记录、对手强度、伤停乘数、盘口线和主要配置都有对应数值检查。禁止将产生负DC低比分概率的ρ/λ组合静默截成0。

本轮没有重新拟合λ、ρ、固定先验或strength，也没有把上轮略差的时序校准候选接入生产。交锋取样、日期顺序和venue别名修复会在受影响输入上改变λ；不能概括为所有λ永远不变。

## 时间证据接口

- kickoff_at、snapshot_at必须为带时区ISO字符串；asof必须为带时区datetime，仍用于研究重放。
- 历史列表home_recent/away_recent/h2h消费gf、ga非负整数，拒绝布尔值。date可为YYYY-MM-DD或带时区ISO时间；played_at/kickoff_at也会检查。只有全部行有比赛时间时才排序；日期不全保持输入顺序并标记input_order_unverified。
- 当天结果须给completed_at。历史available_at/collected_at不得早于completed_at，且不得晚于snapshot。过去的日期只证明日期顺序，不能证明实际采集封存时间。
- 在payload、历史行、odds/opening_odds/elo/asian/injury对象提供available_at、collected_at、feature_as_of时，逐一检查其不晚于snapshot。
- 可额外提供feature_timestamps对象，例如{"elo":"2030-01-01T09:00:00+08:00","league_avg_goals":"2030-01-01T08:00:00+08:00"}，声明各输入在何时可得。
- 不提供时间证据的旧输入继续兼容。输出input_audit列出缺比赛日期、缺完赛时间、缺可得时间、排序依据与被排除的可选信号。status固定表明来源链路未核验，**校验通过不等于真实历史赛前封存已认证**。

输出score_grid和让球probability_trace均记录实际max_goals、联合尾部质量和误差阈值。1e−6控制原始Poisson/DC数值截断；不是预测准确率误差上界，不能用于证明校准／收益提升。

## 实际验证

完整项目tests目录：**416项通过，1项跳过**（penaltyblog未安装）。第二轮新增55项用例，包括非法数值、部分赔率、日期排序、同日未完赛、特征晚于快照、结果早于完赛、输入不被修改、自适应网格以及半全场全场边际。

12组固定虚拟时刻、关闭Monte Carlo的合成回归样本：

| 检查 | 结果 |
|---|---|
| 6组北单完整字典对原始上传代码 | 全部完全相同，包括版本和所有玩法 |
| 6组竞彩λ对第一轮 | 该组无交锋和日期修正，λ完全相同 |
| 竞彩全场胜平负最大概率变化 | 3.3028536894e−7，来自扩网格 |
| 竞彩让球最大概率变化 | 8.9503611443e−7 |
| 半全场聚合全场边际最大误差 | 7.7715611724e−16 |

194场原回填的数值诊断：77场网格从10扩到11，117场保持10；原联合尾部最大6.4018819844e−6，现最大9.8365119716e−7。让球单项最大变化5.4060385412e−6，首选变化0场。诊断Brier由0.607942444661变为0.607942202232，仅反映舍入记录重建中的数值变化，不能作为新模型独立样本外效果证据。

刻意构造的高进球预期压力用例λ=(4.5,4.0)，自适应上限18，联合尾部3.5405056975e−7。旧半全场与目标胜平负最大误差0.002338354585（约0.234个百分点）；新链路5.8286708793e−16。这证明消除了内部概率矛盾，不证明比赛预测更准。

原194场缺少时间、版本和完整输入，先验还包含其之后的训练数据。上轮诊断和研究候选结论仍成立：不能宣传为无泄漏回测；时序校准候选略差，未上线。
