## 1. 让平单独建模 ✅ 已进生产（默认开启）

**问题**：Dixon-Coles 比分矩阵系统性低估 P(让平)。
418 场回填（2026-09-01~30，有竞彩让球）：
- |让球|=1：实际 25.0% vs 模型均值 18.5%（缺口 +6.5pp，n=364）
- |让球|=2：实际 20.9% vs 模型均值 11.8%（缺口 +9.1pp，n=43）
- |让球|=3：实际 22.2% vs 模型均值 6.1%（缺口 +16.1pp，n=9）

**实现**（engine/letdraw.py）：
- 经验先验：TIER_PRIOR = {|rq|=1: 0.25, |rq|=2: 0.21, |rq|>=3: 0.21}
- 分联赛经验贝叶斯收缩（|rq|=1，先验 0.25/20场）：如 欧国联 0.314→0.291、
  欧冠 0.500→0.344、巴西甲 0.444→0.310
- 校准混合：P_adj(让平) = 0.5×P_模型 + 0.5×P_先验，H/A 按原比例重归一
- 规则护栏 letdraw_guard：|让球|=1 且 P(让平)>0.20 → 强制"防让平"标注；
  首选次选概率差<0.15 → 建议降档
- 生产接入：predict() 的 handicap_1x2 输出经 calibrate_handicap_1x2 校准
  （raw 值保留为 p_*_raw 供审计），letdraw_guard 挂在输出上。
  配置项 `letdraw_strength`（默认 0.5，0=关闭）。

**walk-forward 验证**（训练 09-01~20 n=331，测试 09-21~30 n=87）：
- 让球 Brier：w=0.0 → 0.8404；w=0.3 → 0.8288；**w=0.5 → 0.8215**；
  w=0.7 → 0.8146；w=1.0 → 0.8050
- 结论：混合单调改善。默认 w=0.5（w=1.0 虽更优但丢掉全部场次特异信号，过于激进）。

## 2. 弱队进攻 λ 加强收缩 ✅ 已进生产（默认开启）

**问题**：弱赛事（欧国联/友谊赛/亚运）模型系统性高估进球。
69 场弱赛事回填：预测期望 3.09 vs 实际 2.84（**+0.24 球系统性高估**）；
对照组 502 场其他赛事偏差仅 -0.03。典型案例：10-05 的 006 黑山期望 3.1→实际 0 球。

**实现**（engine/predictor.py）：
- WEAK_COMPETITIONS = {欧国联， 友谊赛， 球会友谊， 亚运男足， 亚运女足}
- 弱赛事：shrink_prior 3.0 → 6.0（配置项 `weak_shrink_prior`）
- 弱赛事期望总进球封顶 2.8（按比例缩放，保持主客比；配置项 `weak_goal_cap`）
- 用户显式传入 shrink_prior 时优先尊重用户设置（可复现/可关闭）；
  lambda_notes 标注 weak_competition / shrink_prior_effective / weak_goal_cap_applied

**验证**：
- 封顶 MAE：弱赛事进球 MAE 1.540 → **1.430**（改善约 7%）
- 期望>2.8 的 48 场：预测 3.33 vs 实际 3.00（+0.33）；封顶后 2.80 vs 3.00（-0.20，
  轻微过矫但 MAE 更优）
- shrink_prior 6.0 的精确量级说明：方向（更强收缩）由 +0.24 系统性高估验证；
  6.0 取值为先验翻倍的保守结构选择，精确校准待更多弱赛事样本后做 walk-forward。

## 4. 欧国联爆冷因子 ❌ 数据不支持，不实现

**用户洞察**："欧国联的比赛容易爆冷"。用量化验证（37 场欧国联 vs 534 场其他）：

| 指标 | 欧国联 | 其他 | 显著性 |
|---|---|---|---|
| 平局率 | 18.9% | 24.9% | z=-0.82，不显著（方向反而更低） |
| 热门翻车率 | 35.1% | 45.7% | z=-1.23，不显著（方向反而更低） |
| 让球方输盘率 | 57.7% | 60.3% | 基本持平 |
| 模型 Brier | 0.5556 | 0.5890 | 模型在欧国联反而更好 |
| 平局分量 Brier | 0.1539 | 0.1831 | 校准更好 |

**结论**：常规意义上的"爆冷"（平局多、热门翻车多）在数据上**不成立**。
欧国联真正的特殊性是 **|让球|=1 时让平率 31.4%**（n=35，高于全局 25.0%）——
强队经常只赢 1 球，对让球玩法的体感就是"爆冷"。这一点已由第 1 项的
分联赛让平先验（欧国联 0.291）覆盖，**无需独立的爆冷加权**。
如未来样本扩大后发现显著效应，再议。

## 5. 输出格式升级：对齐竞彩官方玩法（2026-10-06）

**用户指令**：发竞彩官方结算截图，要求"分析结果要像图片这样"；09:32 细化确认两点。

**变更内容**（纯输出项，不改变任何概率逻辑，ENGINE_VERSION 保持 2.5）：

| 玩法 | 变更前 | 变更后 |
|---|---|---|
| ①胜平负 | 不变 | 不变 |
| ②让球胜平负 | 不变 | 不变（用校准后的让平建模概率） |
| ③比分 | 首选无标记 | 首选（概率最高）加粗标记，如 **1-1**(0.133) |
| ④进球数 | 期望+最可能区间 | **保持不动**（用户 09:32 确认）：`进球数：2-3球(0.482)，期望2.66球` |
| ⑤半全场胜平负 | 只有半场胜平负 | 9 种组合（胜胜/胜平/胜负/平胜/平平/平负/负胜/负平/负负），取概率最高 3 种 |
| 冷门比分 | 补充行 | 保留为补充行 |

**引擎层**（engine/poisson.py，engine/__init__.py 导出）：
- `half_full_1x2(λ_h, λ_a, ht_factor=0.44, rho)`：半场比分矩阵（Dixon-Coles）
  × 下半场独立 Poisson → 半场/全场比分联合分布 → 9 种组合聚合。
  注意半场与全场不独立，不可直接相乘边际概率（已用测试锁定）。
  方法学说明：DC 修正施加在半场矩阵上，下半场独立进球会稀释其对全场
  平局的提升，联合推导的 P(平) 略低于直接全场矩阵（λ=1.0/1.0 时 0.309
  vs 0.344），属方法差异非 bug。
- `total_goals_exact(matrix, tail=7)`：总进球 0~6 精确 + "7+" 归尾。
  引擎已输出到 `derivatives["total_goals_exact"]`，但报告行按用户要求
  沿用区间格式，精确分布供后续调用。
- `predict()` 的 derivatives 新增 `half_full_1x2` / `total_goals_exact`
  两个键（4 位小数舍入）；旧键 `half_time` / `total_goals` 原样保留。

**报告模板**（scripts/jingcai_format.py）：
- 本模块是"稳胆排序"报告的唯一格式依据：`format_five_playtypes(pred)`
  返回五大玩法行 + 冷门比分补充行。稳胆三档排序、让平纪律标记、
  分歧标记等现有格式不变，由调用方负责。

**测试**（tests/test_playtypes.py，8 项）：
- 9 种组合加总=1（6 组 λ）；半场负全场胜概率>0（手动验算逻辑）；
  联合边际 ≈ 独立边际（容差内）；联合 ≠ 边际乘积（非独立性锁定）；
  0~7+ 加总=1；"7+" 归尾手动验算；predict() 新键存在且加总=1；
  五个格式化函数输出断言。
- 全量：**140 passed, 1 skipped**（132 基线 + 8 新增）。
