状态：旧结论全部撤回，新结论如下。不改生产引擎参数，未做 git 提交。

## 1. rq 符号定义（已用数据实测核实，非假设）

| rq | 含义 | 数据例证 |
|---|---|---|
| rq < 0 | **主队让球**（rq=-1 = 主让1球） | 斯旺西 2-0 沃特福德，rq=-1，竞彩主胜赔率 1.66（主队热门） |
| rq > 0 | **主队受让**（rq=+1 = 主受让1球） | 斯托克城 1-0 诺维奇，rq=+1，竞彩主胜赔率 3.20（主队冷门） |

194 场中 rq 取值：-3/-2/-1/+1/+2，无 rq=0。

## 2. 正确口径

```
margin = hg - ag
adj = margin + rq
让胜 ⟺ adj > 0；让平 ⟺ adj == 0；让负 ⟺ adj < 0
```

即：rq=-1（主让1球）时，净胜恰为 1 球是让平，净胜 ≥2 球是让胜——与澳客/竞彩结算一致。

## 3. 旧结论错在哪

旧的临时计算用了 `adj_hg = hg - rq`（符号反了）。以 rq=-1 为例：

- 正确：让平 ⟺ margin == 1
- 旧错：让平 ⟺ margin == -1（即**客队净胜 1 球被算成"让平"**，而真正的让平 margin==1 被算成"让胜"）

这个错误同时做了两件事：**压低实际让平率**（真让平被划走），**虚高模型方向命中率**（错口径下模型"看起来"更准）。

## 4. 撤回的数字（全部作废）
